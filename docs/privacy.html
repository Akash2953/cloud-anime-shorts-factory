Privacy Policy

Last updated: 9 November 2026

What this application is

Short Factory is a personal, single-user automation tool. Its owner uses it to generate short narrated anime videos and upload them to a YouTube channel the owner controls. There are no other users, no sign-up, and no public interface.

Data this application handles

  • Google account authorisation. The owner authorises the tool once via Google OAuth, granting the youtube.force-ssl scope so the tool can upload videos and update their visibility on the owner's own channel. The resulting refresh token is stored as an encrypted secret in the owner's private GitHub repository and on the owner's machine.
  • No third-party user data. The tool does not read, collect, store or process personal data belonging to any other person. It does not read comments, subscriptions, viewer analytics or any other channel's data.
  • No tracking. This website sets no cookies, runs no analytics and embeds no third-party scripts.

How data is used and shared

The authorisation token is used solely to publish the owner's own videos. No data is sold, rented or shared with advertisers. Video content is transmitted to YouTube as part of the normal upload process and is then governed by YouTube's own policies.

Third-party services

This application uses YouTube API Services. By using it, the owner is subject to the YouTube Terms of Service and the Google Privacy Policy. Google's How Google uses information page explains how Google handles data obtained through its APIs.

Retention and deletion

The authorisation may be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the stored token. Video content already published can be deleted from the channel at any time.

Children

This application is not directed to children and collects no data from anyone.
